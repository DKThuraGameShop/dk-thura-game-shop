DK THURA Game Shop — phone-first PWA starter

Included:
- index.html: mobile-first shop UI demo
- manifest.webmanifest: installable web-app metadata
- sw.js: basic offline shell cache

Important:
This is a front-end demo only. It does NOT accept real orders, collect payments, or perform top-ups.
Before launch, connect a secure backend (e.g. Firebase), admin authentication, order database,
payment verification, and an authorized top-up API. Never put private API keys in frontend code.
Do not ask customers for payment PINs, passwords, or OTPs.

Phone-only next steps:
1. Extract this ZIP on your phone.
2. Create a GitHub repository from the GitHub website/app.
3. Upload index.html, manifest.webmanifest, and sw.js to the repository root.
4. In repository Settings > Pages, deploy from the main branch / root.
5. Open the published HTTPS website in Chrome > menu > Add to Home screen.
6. Later, use a trusted Android build service or a computer to package a signed APK.
